# ADR-001: Stack technique et architecture plugin VST3

**Statut:** Accepté  
**Date:** 2026-10-08

## Contexte
Développement d'un plugin VST3 synthétiseur sine wave avec les contrôles suivants :
- Fréquence : 1-4000 Hz
- Amplitude : 0-1
- Waveform : Sine/Square/Saw/Triangle
- Phase
- Visualizer oscilloscope

## Decision
**Stack technique :** JUCE 7.x + CMake pour macOS/Linux/Windows  
**Architecture :** Plugin monolithique avec AudioProcessor + AudioProcessorEditor

**Raisons :**
1. JUCE 7.x est l'industrie standard pour plugins VST3 (support multi-plateforme, compresseurs intégrés)
2. CMake offre une build cross-platform fiable
3. Architecture simple et testable pour un plugin minimal

## Conséquences
- **Binaire :** .vst3, .dls (Windows), .component (Linux)
- **Taille binaire :** ~15-25 MB (JUCE bloat)
- **Tests :** Unitaires avec CppUnit, tests audio avec JUCE AudioUnitTestCase
- **Build :** CMake multi-config (Debug/Release)

## Alternatives rejetées
- **RTAS (AAX) :** Hors scope, focus VST3 uniquement
- **Jack/CLAP plugins :** Moins de marché, moins d'outils de mastering
- **JUCE 6.x :** Support abandonné, sécurité compromise

## Implémentation

├── src/
