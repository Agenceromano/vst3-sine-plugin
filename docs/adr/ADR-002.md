# ADR-002: Signature macOS et code signing

**Statut:** Accepté  
**Date:** 2026-10-08

## Contexte
Plugin VST3 doit être signé pour macOS (APFS signature, hardened runtime, entitlements) pour éviter les erreurs "plugin non signé" dans les DAWs.

## Decision
**Outils :** codesign + entitlements  
**Profile:** "Mac Developer" (dev)  
**Entitlements:** libxml (nécessaire pour certains VST3)

**Fichier entitlements :** `Vst3Sine.entitlements`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>com.apple.security.cs.allow-jit</key>
    <true/>
    <key>com.apple.security.cs.allow-unsigned-executable-memory</key>
    <true/>
    <key>com.apple.security.cs.disable-executable-page-protection</key>
    <true/>
    <key>com.apple.security.files.user-selected.read-write</key>
    <true/>
    <key>com.apple.security.network.client</key>
    <true/>
</dict>
</plist>
```

**Commande build :**
```bash
codesign --sign "Developer ID Application: Your Name" \
    --entitlements Vst3Sine.entitlements \
    --force \
    build/Vst3Sine.plugin
```

## Conséquences
- Plugin signé fonctionne dans Logic Pro, Ableton, Cubase
- Pas d'alertes "plugin non signé"
- Entitlements minimales pour compatibilité

## Alternatives
- **Ad-hoc signature :** Fonctionne pour dev mais pas en prod
- **Notarization :** Requise pour distribution (hors scope)

## Implémentation
Ajouter à `CMakeLists.txt` :
```cmake
# macOS code signing
if(PLATFORM_NAME STREQUAL Mac)
    configure_file(Vst3Sine.entitlements.in ${CMAKE_BINARY_DIR}/Vst3Sine.entitlements @ONLY)
    add_custom_command(TARGET Vst3Sine POST_BUILD
        COMMAND codesign
        ARGS --sign "Developer ID Application: Your Name"
             --entitlements ${CMAKE_BINARY_DIR}/Vst3Sine.entitlements
             --force
             ${CMAKE_BINARY_DIR}/Vst3Sine.plugin
        COMMENT "Signing VST3 plugin"
        VERBATIM
    )
endif()
```
